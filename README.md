# AutomataLab – Interactive DFA Simulator

AutomataLab is a frontend-based educational application developed for the **Formal Language and Automata (21CSC301T)** course assignment.

It demonstrates how Deterministic Finite Automata (DFA) can be used for real-world input validation.

## Features

- **Password Verification:** Validates password length and character requirements.
- **Email Validation:** Checks email addresses against a defined format.
- **ATM PIN Verification:** Accepts exactly four numeric digits.
- **Live DFA Visualization:** Displays state transitions as input is processed.
- **Execution Trace:** Shows character-by-character processing and state changes.
- **Test Cases:** Includes accepted and rejected example inputs.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- SVG

## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder.
3. Run `index.html` in your web browser.

No installation, backend or database is required.

## Purpose

The project demonstrates the practical application of finite automata, regular languages, state transitions and input validation.

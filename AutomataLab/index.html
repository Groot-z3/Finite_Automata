Concepts used in this task

What is a DFA?

A Deterministic Finite Automaton is a 5-tuple (Q, Σ, δ, q₀, F), where Q is a finite set of states, Σ is the input alphabet, δ is the transition function, q₀ is the initial state, and F is the set of accepting states. For every state and input symbol, exactly one next state is defined.

What does acceptance mean?

After the entire input has been read, the string is accepted if and only if the machine is in an accepting state. Otherwise it is rejected.

Syntax validation vs semantic validation

A finite automaton can check whether an input follows a defined character pattern. It cannot, by itself, verify external facts such as whether an email inbox exists, whether a PIN belongs to a bank account, or whether a password has appeared in a compromised-password database.
